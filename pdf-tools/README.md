# Tawhid's PDF Tools

A browser-based PDF utility website hosted as a subdirectory of the existing GitHub Pages portfolio.

## Live site
https://tawhidurrahmansadek.github.io/pdf-tools/

## Included tools
- Merge PDF
- Split PDF by page range
- Rotate PDF
- Organize PDF (remove/reorder pages)
- JPG/PNG to PDF
- Add page numbers

## Technology
HTML, CSS, Vanilla JavaScript and pdf-lib loaded from a CDN. PDF files are processed in the browser and are not uploaded to a backend. An internet connection is required to load pdf-lib.

## Notes
Large PDFs may exceed a mobile browser's memory limits. Test with copies of important documents. This project was added under `pdf-tools/` to preserve the existing portfolio homepage.
